How the C and C++ projects differ

The two languages get different kinds of work, so nothing repeats. C projects are small, file-and-bytes tools where you do everything by hand. C++ projects are long-running, interactive programs where abstraction and RAII are the point.

CC++
ProjectsDuplicate file finder, stash-fsck (log verifier)Redis clone, terminal UI for stash
Kind of programRun-once command-line tools that read files and exitLong-running, event-driven programs that talk to a socket
What it trainsRaw bytes, syscalls, manual memory, defensive parsing, fuzzingRAII, move semantics, classes and templates, variants, event loops
Tooling focusValgrind, ASan, libFuzzer or AFL++, MakefileCMake, clang-tidy, sanitizers, unit-test framework
Tip: keep one git repo per project, write the README first (scope and "done when"), and commit at every ticked box. Reference books: Beej's Guide, The Linux Programming Interface, Crafting Interpreters, Database Internals, the Tokio tutorial.
